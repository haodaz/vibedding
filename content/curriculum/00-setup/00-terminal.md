## 先说结论
你不需要"学终端"。这个项目里 90% 的时候你只会用下面 8 条，而且大部分是让 AI 帮你敲的。你要做的是**看得懂**。

| 命令 | 人话 | 成功长什么样 |
|---|---|---|
| `pwd` | 我在哪个文件夹 | 打出一个路径 |
| `ls` | 这个文件夹里有什么 | 列出文件名 |
| `cd 文件夹名` | 进到那个文件夹 | 没有任何输出 = 成功（终端的沉默是金） |
| `cd ..` | 退回上一层 | 同上 |
| `cat 文件名` | 把文件内容打出来看 | 显示内容 |
| `bash 脚本.sh` | 跑一个脚本 | 看脚本自己打印什么 |
| `npm run dev` | 启动网页 | 出现一个 `http://localhost:xxxx` 的网址 |
| `Ctrl + C` | 停掉正在跑的东西 | 光标回来了 |

## 三个让人不再害怕的事实
1. **终端不会因为你输错命令而坏掉。** 最坏就是报个 `command not found`，重新输就行。
2. **没有输出通常是好事。** `cd` 成功时什么都不显示。
3. **红字不一定是错。** 很多 warning 是红的但无害。真正的错通常带 `Error` / `failed` / `✘`。

## 和 AI 配合的方式
在 Claude Code 或 Cursor 里，直接说"帮我运行体检脚本"，它会敲。你看结果。**如果它敲的命令你看不懂，让它解释那条命令。** 这是学终端最快的方式：按需学，不背。
