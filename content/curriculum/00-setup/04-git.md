## git 是什么
游戏里的**存档**。每次做出一点进展就存一下，搞坏了就读档。就这么简单，别的先不学。

## 5 条命令
| 命令 | 人话 | 什么时候用 |
|---|---|---|
| `git status` | 我改了哪些文件？ | 随时，看一眼不花钱 |
| `git add .` | 把所有改动放进"待存档" | 存档前 |
| `git commit -m "一句话"` | 存档，写一句这次干了啥 | 灯亮了 / 一个任务完成了 |
| `git log --oneline` | 看所有存档点 | 想知道自己走了多远 |
| `git checkout -- 文件名` | 这个文件我改坏了，回到上次存档 | 搞坏的时候 |

分支、合并、rebase、远程仓库：**现在不用学**。等你想把东西传到 GitHub 给别人看的时候，再学 `git push`，那是一张新的卡。

## 练习
```bash
git status
```
```bash
git add .
```
```bash
git commit -m "Day 0: 平台骨架搭好了"
```
```bash
git log --oneline
```

## 和 AI 配合
说"帮我存个档，说明是 xxx"，它会跑 add + commit。你只需要偶尔自己 `git log --oneline` 看一眼历史，会有成就感。

## 一个原则
**灯亮了就 commit。** 任何看得见的进展都值得一个存档点。存档太多不会有坏处，存档太少会哭。
