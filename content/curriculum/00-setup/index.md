# 模块 0 · 起飞前

这个模块不学编程。它只做一件事：**让你在电脑上敲一条命令，板子上的灯就亮了。**

对门外汉来说，嵌入式最大的门槛不是 C 语言，而是"电脑和板子之间到底怎么连起来的"这整条链路：

```
你的代码 → 编译器 → 二进制文件 → 烧录器(ST-Link) → 芯片的 Flash → 上电运行
```

每一环都可能出错，而且报错信息对新手很不友好。所以模块 0 的任务就是把这条链路**亲手走通一遍**，走通了以后所有任务都是"改代码 → 重复这条链路"。

## 完成这个模块后你能
- 说出自己板子的芯片型号、主频、Flash 大小（不用背，会查就行）
- 用一条命令编译、一条命令烧录、一条命令看串口
- 板子不识别时知道从哪三个地方排查
