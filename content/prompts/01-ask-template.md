---
## 模板

```
我的板子：STM32F103C8T6 蓝药丸，用 PlatformIO + Arduino 框架，ST-Link 烧录。
我想做：[一句话]
我已经试了：[代码 / 步骤]
现象：[看到了什么]
期望：[应该看到什么]

请先解释原理，再给代码。代码里每个引脚号请标注你是怎么确定的。
```

## 为什么要这样问
- **没说板子型号**，AI 会默认你用 Arduino UNO，引脚全错
- **没说框架**，它可能给你 HAL 的代码而你在用 Arduino，或者反过来
- **"先解释再给代码"**，逼它讲清楚，也逼你听懂。vibe coding 不等于不理解，等于理解得更快

## 核对清单（AI 给完答案后）
- [ ] 引脚号：去板子丝印或原理图上核对
- [ ] 库名：去 https://registry.platformio.org 搜一下是否真的存在
- [ ] 寄存器名：在参考手册里搜一下
