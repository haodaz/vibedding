# Module 6 · Capstone Project
Candidate projects (pick one, or come up with your own):
- Desktop temperature & humidity station (sensor + OLED + button to switch pages)
- Computer CPU usage monitor (receive data over serial + display on screen / LED bar)
- Automatic plant waterer (ADC soil moisture + relay + state machine)
- Night light (photoresistor + PWM + touch sensor)

The flow: write requirements → have the AI break them into task cards → for each card, "build → write a journal entry."
